# 工作区与布局

NyaTerm 的核心体验不是“单个终端标签页”，而是一个可组合的工作区：你可以同时打开多个会话、拆分多个窗格，并把常用面板固定在左右两侧。

## 工作区的组成

典型工作区由几部分组成：

- **中央区域**：标签页与终端窗格
- **左侧活动栏 / 面板**：文件浏览器、网络、Security/Auth、云同步、设置
- **右侧活动栏 / 面板**：已保存连接、AI Assistant、活动会话、命令历史、资源监控
- **底部辅助区域**：快捷命令、串口发送、录制、锁定

这些区域不是固定死的单一页面，而是围绕当前活跃会话动态协作。

## 标签页

每个标签页都可以承载一个会话，也可以继续拆分成多个窗格。

你可以对标签页执行这些常见操作：

- 新建会话
- 关闭当前标签
- 在标签之间切换
- 自定义标签名
- 给标签设置颜色
- 复制当前会话，或复制后执行启动命令
- 通过拖拽把标签停靠到其他分屏区域
- 重新连接会话
- 查看会话信息

这让 NyaTerm 很适合用来区分：

- 不同环境
- 不同项目
- 不同任务阶段

## 命令面板

**命令面板** 是一个可搜索的浮层，用 `Ctrl / Cmd + Shift + S` 打开（设置中标为 **打开命令面板**）。它检索三类条目：

- **活动会话** — 当前已打开的标签
- **正在建立的会话** — 已发起但还没连上的会话，包含失败原因
- **已保存连接** — 连接列表里的条目，选中即发起连接

用键盘上下选择、回车打开。当打开的标签和连接很多时，这是最快的导航方式。

命令面板只检索会话和连接，**不包含**打开设置、切换面板、锁屏这类应用级动作——那些走顶部菜单或快捷键。

## 分屏能力

在标签页上右键，可以把当前会话拆成：

- **水平分屏**
- **垂直分屏**

分屏后的窗格仍然属于同一个标签页，但每个窗格都能承载自己独立的会话内容。较新的工作区还支持把标签拖拽到目标停靠区域，从而更直观地把会话移动到水平或垂直分屏中。适合的场景包括：

- 一个窗格看日志，一个窗格执行命令
- 并排比较两台主机状态
- 左边本地终端，右边远程 SSH
- 串口输出和 SSH 排障命令同时观察

## 会话与工作区的关系

工作区里有两个容易混淆的概念：

1. **逻辑标签页 / 窗格树**：决定一个标签内部如何分屏
2. **运行时窗口布局**：决定不同标签当前挂在哪个工作区叶子位置

对普通使用者来说，可以简单理解成：

- 标签页负责组织任务
- 分屏负责并排观察
- 活动窗格决定当前命令发往哪里

## 布局恢复与工作区间距

NyaTerm 会保存终端窗口布局，重启或重新打开工作区时尽量恢复之前的标签、分屏和活动位置。这对长期维护同一组主机、日志和本地构建任务很有帮助。

如果你希望终端之间留出更明显的视觉边界，可以在终端相关设置中调整 **Workspace Padding**。它只影响工作区的视觉间距，不改变远端 shell 或本地 shell 的行为。

## 左右侧面板

### 左侧

左侧更偏“能力入口”，通常包括：

- 文件浏览器
- 网络
- Security/Auth
- 云同步
- 设置

其中 **文件浏览器** 不只是静态目录树：在 SSH 会话中，它可以和当前终端 cwd 联动，并支持把当前目录或条目路径直接发回终端继续补命令。

其中 **云同步** 面板更偏“跨设备配置同步”的运行态入口：它会展示当前状态、最近的同步活动，并在发生冲突时提供直接处理入口。

如果你只是想快速知道“最近同步成功了吗”，在工作区历史面板里查看通常比回到设置页更直接。

### 右侧

右侧更偏“运行态信息”，通常包括：

- 已保存连接
- AI Assistant
- 活动会话
- 命令历史
- 资源监控
- NVIDIA GPU 监控
- Ascend NPU 监控
- 进程管理
- Docker 管理

这五个监控面板只对 SSH 会话有意义，各自由 **设置 → 终端** 中的开关控制是否显示；关闭开关会同时隐藏对应的活动栏图标。资源监控、进程管理和 Docker 管理默认开启，两个加速卡监控面板默认关闭。详见 [终端功能 → 远程主机监控面板](./terminal#远程主机监控面板)。

如果你的工作流是“先选连接，再看运行状态，必要时再调用 AI 分析”，这种左右分工会很自然。

## AI Assistant 面板

右侧的 **AI Assistant** 不是独立弹窗，而是工作区中的常驻面板。它适合配合当前活跃窗格做这些事：

- 根据自然语言生成一条终端命令
- 解释最近终端输出
- 解释当前选中的文本
- 分析错误并给出修复建议
- 生成可审批的命令卡片并执行
- 把合适的命令保存为快捷命令

因为它和当前会话上下文直接联动，所以放在工作区右侧通常比额外开窗口更顺手。

## 底部辅助区域

工作区底部用于承载一些不适合一直占满侧栏的能力，例如：

- **快捷命令**：保存可复用命令片段并支持变量输入
- **串口发送**：适合频繁向串口设备发固定文本
- **录制**：开始或停止当前会话录制
- **锁定**：快速锁屏

这也是 NyaTerm 和“普通多标签终端”差异较大的地方：它不是只让你开终端，而是把会话周边动作也组织到工作区里。

## 子窗口

某些操作会打开独立子窗口，而不是把所有内容都塞进主界面，例如：

- 设置
- 新建连接
- 快捷命令编辑
- 自动上传提示

这样做的好处是：

- 不打断主工作区当前会话
- 复杂配置可以独立完成
- 演示和截图时结构更清晰

## 托盘、子窗口与窗口状态

如果你在 **设置 → 常规** 中开启 **关闭时最小化到托盘**，关闭主窗口时应用不会立刻退出，而是转为后台驻留。主窗口也可以被隐藏后再从托盘或系统入口唤回。

NyaTerm 会尽量记住子窗口的位置、大小和模态关系；设置、新建连接、远程文件编辑或自动上传窗口再次打开时，会使用更稳定的焦点与窗口状态。

这适合：

- 需要保留活动会话
- 希望让同步 / 备份继续在后台运行
- 需要后续快速从托盘重新唤起主窗口

## 推荐的工作流组合

### 组合一：本地 + 远程

- 标签 1：SSH 登录远程主机
- 标签 2：本地终端执行构建或 Git 命令
- 右侧打开命令历史或 AI Assistant

### 组合二：双窗格排障

- 左窗格：实时日志
- 右窗格：执行诊断命令
- 再打开资源监控观察 CPU / 内存变化

### 组合三：文件 + 终端联动

- SSH 终端进入目标目录
- 文件浏览器同步到当前路径
- 打开远程文件，本地编辑后自动回传
- 把当前目录或文件路径直接发送到终端继续执行命令

### 组合四：多主机同步操作

- 打开多个 SSH 会话连接到不同主机
- 创建同步输入组，将需要同步的会话加入
- 在任意一个会话中输入命令，所有组内会话同时执行

## 同步输入组

同步输入组允许你将多个终端会话组织在一起，在一个会话中输入的命令会同时广播到组内所有活跃会话。

### 创建与管理

1. 在右侧活动栏中打开 **同步输入组** 面板
2. 点击 **新建组** 创建一个同步组
3. 为组设置名称和颜色
4. 从活跃会话列表中选择要加入的会话

### 会话筛选

当活跃会话较多时，可以使用筛选功能：

- **全部**：显示所有活跃会话
- **可用**：显示未加入当前组的会话
- **已加入**：显示已在当前组中的会话
- **同主机**：快速选中与当前选中会话相同主机的所有会话
- 搜索框支持按名称、类型、主机或会话 ID 搜索

### 广播控制

- 可以对整个组启用或暂停广播
- 可以对组内单个会话暂停同步
- 组内缺失的会话（已关闭）会标记为 Missing，可一键清理

### 适用场景

- 多台服务器同时执行相同运维命令
- 集群环境下的批量配置变更
- 多环境同步部署验证

### 快捷命令广播

在快捷命令面板中，也可以选择 **发送到所有会话**，将命令一次性发送到所有活跃会话。
